**简要说明**：3.0.0 的文件工作区以设备本地存储为主；只有你主动分享、开启局域网传输或授权系统/第三方服务时，相关数据才会离开设备。免费版使用广告；应用不启用 Firebase 分析或崩溃诊断。旧版本可能包含 Google Drive 和不同的收集流程，请阅读下文版本说明。

## 1. 适用范围 {#scope}

本政策适用于独立开发者 Mac Zhou 提供的**文件夹**（英文显示名 Folder，App Store ID **1563518405**），不适用于本站其他软件。下文的 3.0.0 描述以该版本源码为准；你实际安装的版本、系统权限和购买权益决定可用功能。旧版本差异见第 5 节。阅读本政策本身不构成跟踪或诊断授权。

## 2. 本地文件与访问 {#local}

3.0.0 在设备上读取和保存你导入的文件、文件夹、PDF、阅读状态、收藏、最近打开、垃圾桶清单、设置及购买权益缓存。工作区通过扫描本地目录展示；稀疏元数据只记录必要状态，不作为文件目录索引。应用不提供开发者运营的文件同步账号，也不自动把文件内容上传到开发者服务器。系统设备备份是否包含应用数据取决于你的设备与备份设置。

应用锁密码、恢复码和生物识别用于访问控制；应用锁不等于逐文件加密。你可另行创建有密码保护的本地备份，并自行保管备份文件与密码。相机扫描、照片导入、生物识别和本地网络仅在相应功能需要时使用系统权限。关闭应用锁不会替你删除文件。

## 3. 传输与分享 {#transfer}

使用“从电脑传文件”时，应用在你开启期间于同一局域网提供临时 HTTP 页面。知道页面地址的同网设备无需登录即可上传；如果你另行启用下载，该设备还可获取所选范围内的文件。HTTP 本身不加密，请只在可信的私有网络使用，完成后停止传输。应用进入后台或空闲超时会停止服务；不向开发者中转文件。

分享、用其他应用打开或导出文件由你发起，系统会将选定内容交给你选择的接收方；接收方的隐私规则另行适用。网页端或接收方保存的副本不会因你删除应用内原件而自动删除。

## 4. 广告与购买 {#services}

3.0.0 免费版集成 Google Mobile Ads。广告 SDK 可能处理 IP 地址、设备或广告标识符、广告互动和诊断信息。应用使用 Google UMP 处理适用地区的广告同意，使用系统 ATT 提示申请跟踪权限；拒绝跟踪不等于移除所有广告。购买并识别专业版权益后停止加载广告。广告相关处理参见 [Google 隐私政策](https://policies.google.com/privacy) 和 [Google Mobile Ads 数据披露](https://developers.google.com/admob/ios/privacy/data-disclosure)。

3.0.0 保留 Firebase Analytics 与 Crashlytics 的 SDK 依赖，但不初始化 Firebase，不提供匿名诊断开关，也不主动发送分析事件或崩溃报告。此说明不涵盖 Google Mobile Ads 自身的数据处理；参见上文广告说明。

专业版由 Apple StoreKit 处理购买和恢复。Apple 管理支付账户、卡片及交易记录；开发者不接收你的银行卡资料。3.0.0 只销售一次买断；旧订阅仅用于识别既有权益。参见 [Apple 隐私政策](https://www.apple.com/legal/privacy/)。

## 5. 旧版本差异 {#legacy}

已发布的 2.x 版本与 3.0.0 的功能、SDK 启动和同意流程不同。旧版可能提供 Google Drive 授权与文件访问、局域网媒体投送及按月/按年订阅；Google Drive 操作会把你选择的文件、文件元数据和授权所需信息直接交给 Google 服务，不是 3.0.0 的本地工作区行为。历史源码中存在启动时配置 Firebase、为免费用户启动广告的实现；**不要把上文“3.0.0 不启用 Firebase”理解为旧版的保证**。请以设备中的版本号、实际权限提示和旧版功能为准。如需了解旧版特定数据处理，请按末尾方式联系开发者。

## 6. 保存、删除与选择 {#retention}

本地文件、元数据与设置通常保留到你删除相应内容或应用数据；垃圾桶开启时，删除的项目在应用内可恢复，关闭时会直接删除。手动创建的备份、已分享副本、系统备份和第三方服务记录需分别在其所在位置管理。卸载应用不一定清除 Apple 设备备份、Google 服务记录或 Apple 交易记录。

你可管理系统权限、广告同意、文件分享和局域网传输。根据适用法律，你可能拥有访问、更正、删除、撤回同意或投诉等权利。对于仅存在你设备上的文件，开发者无法代为读取或删除。对于开发者可控制的服务数据，请联系我们核查可执行的请求；第三方服务的保留期限由其设置和规则决定，本政策不编造固定天数。
