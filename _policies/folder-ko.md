**요약:** 파일 내용은 주로 기기에서 처리되며 개발자가 운영하는 파일 서버로 자동 업로드되지 않습니다. 3.0.0 정식 버전은 기본적으로 Firebase에 사용 분석과 충돌 보고서를 전송합니다. 무료 버전에는 Google 광고가 표시됩니다. Pro는 광고를 제거하지만 분석과 진단은 중단하지 않습니다.

## 1. 적용 범위 {#scope}

이 방침은 Vanto 팀의 **FileNook**(이전 이름 'Folder', App Store ID **1563518405**)에 적용되며 이 사이트의 다른 앱에는 적용되지 않습니다. 아래 3.0.0 설명은 현재 구현을 기준으로 하므로 설치된 버전과 다를 수 있습니다.

## 2. 기기 내 파일과 접근 {#local}

가져온 파일, 스캔 및 변환 결과, 읽기 진행 상태, 즐겨찾기, 휴지통, 설정, 필요한 파일 상태는 기기에 저장됩니다. 개발자가 운영하는 파일 동기화 계정은 없으며 파일 내용, 사진, 오디오·비디오, OCR 결과 또는 암호를 자동 업로드하지 않습니다. 기기 백업에 앱 데이터가 포함되는지는 시스템 설정에 따라 달라집니다.

카메라, 사진, 시스템 파일, 생체 인증 및 로컬 네트워크는 해당 기능을 사용할 때 접근합니다. 앱 잠금은 앱 접근을 제한하는 기능이며 파일별 암호화는 아닙니다. 암호화된 백업을 만들 경우 암호를 안전하게 보관하세요.

## 3. 전송과 공유 {#transfer}

'컴퓨터에서 파일 전송'을 시작하면 같은 네트워크에서 주소를 아는 기기가 **암호화되지 않은 HTTP**로 업로드할 수 있습니다. 다운로드를 켜면 선택한 범위의 파일에도 접근할 수 있습니다. 신뢰할 수 있는 네트워크에서만 사용하고 완료 후 중지하세요. 파일은 개발자 서버를 거치지 않습니다.

사용자가 파일을 공유하거나 내보내거나 다른 앱에서 열면 선택한 내용이 수신자에게 전달됩니다. 수신자가 보관한 사본과 처리 방식에는 해당 서비스의 정책이 적용됩니다. 앱의 원본을 삭제해도 외부 사본은 삭제되지 않습니다.

## 4. 분석·광고·구매 {#services}

3.0.0 정식 버전은 Firebase Analytics를 기본적으로 활성화하고, 해당하는 Crashlytics 충돌 보고서를 다음 실행 시 전송하여 기능 사용 현황을 파악하고 오류를 조사합니다. 자체 이벤트에는 정해진 작업·결과 유형, 소요 시간, 개수·크기 구간만 기록하며 **파일 내용과 이름, 경로, 검색어, 인식된 텍스트, 자막, 암호는 전송하지 않습니다.** 단, Firebase SDK는 앱 인스턴스 식별자, 기기·시스템 정보 및 자동 세션 데이터를 처리할 수 있습니다. 앱은 사용자 ID를 설정하지 않으며 앱 내 분석 끄기 스위치도 제공하지 않습니다. [Firebase 개인정보 안내](https://firebase.google.com/support/privacy)를 참고하세요.

무료 버전은 Google Mobile Ads의 배너 광고와 보상형 광고를 사용합니다. 광고 SDK는 IP 주소, 기기 또는 광고 식별자, 광고 상호작용 및 진단 정보를 처리할 수 있습니다. 해당 지역의 광고 동의는 Google UMP로 처리하며 시스템 ATT 추적 권한은 별도로 요청합니다. 추적을 거부해도 광고가 모두 사라지는 것은 아닙니다. Pro 권한이 확인되면 광고를 불러오지 않지만 위에서 설명한 분석과 진단은 계속됩니다. [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)과 [Mobile Ads 데이터 공개 안내](https://developers.google.com/admob/ios/privacy/data-disclosure?hl=ko)를 참고하세요.

Pro의 일회성 구매와 구매 복원은 Apple StoreKit에서 처리합니다. 개발자는 카드 정보를 받지 않습니다. [Apple 개인정보 처리방침](https://www.apple.com/legal/privacy/)을 참고하세요.

## 5. 이전 버전과의 차이 {#legacy}

이전 버전에는 Google Drive, 미디어 전송, 월간·연간 구독이 포함될 수 있으며 권한, 광고 및 Firebase 시작 방식도 다를 수 있습니다. Google Drive를 사용하면 사용자가 선택한 데이터가 Google에 전달됩니다. 3.0.0의 동작이 이전 버전에도 적용된다고 가정하지 말고 설치된 버전과 권한 안내를 확인하세요.

## 6. 보관과 선택 {#retention}

기기 내 데이터는 일반적으로 해당 내용이나 앱 데이터를 삭제할 때까지 보관됩니다. 휴지통을 켜면 삭제한 항목을 앱에서 복원할 수 있습니다. 직접 만든 백업, 기기 백업, 공유한 사본, 광고·Firebase 데이터 및 Apple 거래 기록은 각각의 위치에서 관리해야 합니다. 앱을 제거해도 이 사본들이 모두 삭제되는 것은 아닙니다.

시스템 권한, 광고 동의, 공유 및 로컬 전송은 관리할 수 있습니다. 현재 앱 내 분석 끄기 스위치는 없습니다. 기기에만 있는 파일은 개발자가 대신 읽거나 삭제할 수 없습니다. 그 밖의 데이터에 대한 열람, 삭제 또는 동의 철회 요청은 적용 법률에 따라 문의해 주세요. 제3자 데이터의 보관 기간은 해당 서비스의 정책을 따릅니다.
