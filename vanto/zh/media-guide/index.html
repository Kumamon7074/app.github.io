媒体整理指南

一套适用于 Local、SMB 与 WebDAV，并可被 Vanto、Jellyfin 和 Kodi 稳定识别的推荐结构。

最近更新：2026 年 9 月 7 日适用于 Vanto 当前版本
本页内容查找影片资料快速规则推荐结构电影剧集、季与单集图片命名外挂字幕来源与编辑能力兼容与高级规则检查与排查

查找影片资料

先补标题、简短介绍和图片，其余按需填写，不需要学习 XML。

1. 确认是哪部作品

用片名或人物姓名搜索。季与单集默认搜索所属剧名，在网站内核对年份与编号（如 S01E03）；注意翻拍、特别篇及分集顺序差异，不改变文件身份。

2. 选择参考资料

  • 豆瓣电影

    核对中文片名和别名。

  • IMDb

    核对原名与演职员。

  • TMDB

    查阅电影、剧集和人物条目。

3. 查阅并填写

在 NFO 编辑页点击“查找资料”。系统地区为中国大陆时默认豆瓣，其它地区默认 TMDB；可切换站点，并在本机记住手动选择。确认关键词后在所选网站查找，进入正确作品或人物条目查阅资料和图片，再返回手动填写。网站无法访问时，可手动换站或复制关键词。

iPhone 关闭浏览界面即可返回；iPad 和 Mac 可将 Vanto 与浏览器并排，复制文字或拖入图片。Apple TV 只读，请在 iPhone、iPad 或 Mac 编辑。

4. 导入图片

可从照片、文件、拖放或图片链接导入。影片详情页网址不是图片直链；链接导入失败时，请使用获准下载的图片文件。海报和人物头像使用 2:3，背景与单集图使用 16:9。

公开可见不等于可以任意使用。请核对来源条款和图片许可，使用自己的内容或已获授权的素材。

5. 保存更改

整部剧、当前季和单集在同一页编辑，单集只需标题、简介和图片。“保存更改”提交会话内全部已修改条目。App 终止后，尚未保存的图片无法恢复。

快速规则

  • 一部电影使用一个 片名 (年份) 文件夹，并只保留一个主视频。
  • 剧集使用 剧名 (年份)/Season 01/剧名 - S01E01。
  • NFO 不是扫描或播放的前置条件；没有 NFO 时，Vanto 会根据目录名和文件名建立媒体结构。
  • 目录和文件名确定媒体身份；NFO、图片与字幕只补充展示信息。
  • 在 Vanto 外修改文件后，请刷新来源；在 Vanto 内编辑保存后，当前片库会自动更新。
最稳妥的原则

保持名称简洁并加入年份。不要用 NFO 改写季号、集号或目录关系，也不要依赖复杂发布组名称来表达媒体身份。

NFO、图片和字幕都是可选文件。只保留视频也能入库；加入这些文件后，Vanto 会优先使用明确绑定的本地信息。

电影

电影目录建议只放一个主视频。预告片、花絮、样片和访谈分别放入 Trailers、Extras、Samples 或 Interviews 子目录，它们可以继续浏览，但不会作为独立正片进入首页。

电影优先读取与视频同名的 NFO，也兼容单主视频目录中的 movie.nfo。当前 Vanto 不把同一目录中的多个视频合并成一个多版本条目；需要保留多个版本时，请为每个版本建立独立电影目录。

查看电影 NFO 示例
<?xml version="1.0" encoding="UTF-8"?>
<movie>
  <title>降临</title>
  <originaltitle>Arrival</originaltitle>
  <year>2016</year>
  <plot>影片简介</plot>
  <genre>科幻</genre>
  <rating>7.9</rating>
  <uniqueid type="tmdb" default="true">329865</uniqueid>
</movie>

剧集、季与单集

剧名来自剧集根目录，季号来自季目录，集号来自视频文件名。特别篇使用 Season 00 和 S00E01。包含连续多集的单个视频可以使用 S01E01-E02，但拆分为单集文件通常能获得更清晰的播放进度和单集信息。

整部剧使用 tvshow.nfo，季使用季目录中的 season.nfo，单集使用与视频同名的 NFO。NFO 中的季号和集号不会改变扫描得到的目录关系。

查看剧集、季和单集 NFO 示例

整部剧：tvshow.nfo

<?xml version="1.0" encoding="UTF-8"?>
<tvshow>
  <title>示例剧</title>
  <originaltitle>Example Show</originaltitle>
  <year>2026</year>
  <plot>整部剧简介</plot>
  <genre>剧情</genre>
  <uniqueid type="tvdb" default="true">123456</uniqueid>
</tvshow>

当前季：Season 01/season.nfo

<?xml version="1.0" encoding="UTF-8"?>
<season>
  <title>第一季</title>
  <seasonnumber>1</seasonnumber>
  <plot>第一季简介</plot>
</season>

单集：与视频同名的 NFO

<?xml version="1.0" encoding="UTF-8"?>
<episodedetails>
  <title>第一集</title>
  <showtitle>示例剧</showtitle>
  <season>1</season>
  <episode>1</episode>
  <aired>2026-01-01</aired>
  <plot>本集简介</plot>
</episodedetails>

图片命名

对象推荐文件位置
电影poster.jpg、fanart.jpg电影目录
整部剧poster.jpg、fanart.jpg剧根目录
季poster.jpg、fanart.jpgSeason 01 目录
单集Example Show - S01E01-thumb.jpg单集视频目录

建议使用 JPG 或 PNG。NFO 中的相对图片文件名必须与真实文件精确一致。Vanto 不按相似文件名猜图，无法确认时宁愿不展示，以避免错误封面。

缺少图片

SMB 与 WebDAV 没有已确认 Sidecar 图片时直接显示对应媒体类型的默认封面，不读取视频帧，也不把单集截图继承给整部剧或季。

外挂字幕

字幕与视频放在同一目录，并使用完全相同的主文件名：

Arrival (2016).mkv
Arrival (2016).zh-Hans.srt
Arrival (2016).en.forced.ass
Arrival (2016).zh-Hant.vtt
  • 语言可使用 zh-Hans、zh-Hant、en、ja 等标识。
  • 可保留 forced 等常见用途后缀；是否启用仍由播放器中的字幕选择决定。
  • 文本字幕支持 SRT、ASS、SSA、VTT 与 SMI；图片字幕支持 PGS、SUP 以及同名配对的 IDX + SUB。
  • 外挂字幕不写入 NFO。NFO 描述媒体，字幕始终是绑定具体视频的独立文件。
  • 同一语言有多份不同字幕时，从 .2 开始增加序号，例如 Arrival (2016).en.2.srt；相同内容不会重复保存。

来源与编辑能力

在 iPhone、iPad 和 Mac 上，连接可写入的 SMB 或 WebDAV，即可免费编辑 NFO。Apple TV 支持读取，不提供编辑。

编辑电影与整部剧的标题、简介、图片和演职人员。

在同一页切换季与单集；单集只保留标题、简介和封面，编辑更轻松。

季可编辑标题、简介、海报与背景；单集只编辑标题、简介与 16:9 封面，不提供评分、播出日期或演职人员编辑。

来源扫描与读取在 Vanto 中写回
Local视频、NFO、图片与字幕不提供；请在文件系统中管理
SMB / WebDAV视频、NFO、图片与字幕iPhone、iPad 与 Mac 支持，取决于目录权限
Apple TV读取并展示已扫描内容只读

iPhone、iPad 和 Mac 上可写的 SMB 与 WebDAV 详情页可以创建或更新电影、整部剧、当前季或当前集的 NFO 与图片。演员头像按 2:3 裁剪为 JPG，电影保存在媒体目录的 .actors，剧集、季和单集共用剧根目录的 .actors，并由 NFO 的标准 <actor><thumb> 相对路径引用；删除头像只移除引用，不自动删除可能复用的文件。在线下载或从文件导入的字幕默认按上述命名写入视频所在目录，成功后同一 NAS 来源的其它设备也可在刷新后使用；Vanto 不再额外保留一份设备副本。NAS 明确没有写入成功时，可由用户选择仅保存到当前设备。Apple TV 不写回 NAS，在线字幕只保存在当前设备。

写回范围

一次保存本次会话中已修改的草稿，不重写未修改的季或单集。保存前确认 NAS 账号具有目标目录的创建、替换、重命名与删除权限。

兼容与高级规则

查看 Jellyfin、Kodi 与其他可识别命名
  • 为了兼容 Kodi，可以在剧集根目录额外放置 season01-poster.jpg 和 season01-fanart.jpg。Vanto 与 Jellyfin 的推荐结构仍是季目录中的 poster.jpg 和 fanart.jpg。
  • 人物使用标准 director、credits 和带 name / role / order / thumb 的 actor；Vanto 不为导演或编剧创建私有头像字段。
  • Kodi 使用的 namedseason、seasonplot 等季级字段可以保留在 tvshow.nfo，但 Vanto 的季标题与简介以季目录中的 season.nfo 为准。
  • Vanto 还能识别 1x01、本地化季目录和其他常见命名；新整理的媒体仍建议统一使用本页主结构。
  • 标题存在歧义时，优先在 NFO 中写入明确的 uniqueid，不要依赖不同应用各自的文件名 ID 扩展。

检查与排查

  • NFO 使用 UTF-8 XML，根节点必须与对象一致：movie、tvshow、season 或 episodedetails。
  • 单个 NFO 最大 2 MB；Vanto 最多读取 32 位人物。
  • 未知 XML 元素会被忽略，不会阻止视频扫描与播放。
  • 信息未更新时，依次检查目录层级、文件名、XML 根节点、大小写、图片位置和来源权限，再刷新当前来源。
