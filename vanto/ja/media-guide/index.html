メディア編成ガイド

Vanto、Jellyfin、およびKodiが確実に識別できる推奨Local、SMB、およびWebDAVレイアウト。

最終更新：2026年9月7日現在の Vanto リリースの場合
このページでは作品情報を探す簡単なルール推奨レイアウト映画番組、シーズン、エピソード作品のネーミング外部字幕ソースと編集互換性と高度なルールチェックとトラブルシューティング

作品情報を探す

まずはタイトル、短いあらすじ、画像を追加しましょう。他の項目は任意で、XML の知識は不要です。

1. 作品を確認する

作品名または人物名で検索します。シーズンやエピソードは番組名で検索し、公開年と番号（S01E03 など）をサイト上で確認してください。ファイルの識別情報は変更しないでください。

2. 参考サイトを選ぶ

  • Douban

    中国語の作品名や別名を確認。

  • IMDb

    原題やクレジットを確認。

  • TMDB

    映画、テレビ番組、人物の情報を確認。

3. 調べて入力する

NFO 編集画面で「情報を探す」を選びます。システムの地域が中国本土の場合は Douban、それ以外は TMDB が既定になります。サイトは切り替えられ、手動の選択はこのデバイスに記憶されます。キーワードを確認して検索し、正しい作品や人物のページで情報や画像を調べてから、戻って手動で入力します。サイトにアクセスできない場合は、サイトを切り替えるかキーワードをコピーしてください。

iPhone はブラウザを閉じると戻れます。iPad や Mac では Vanto とブラウザを並べて文字をコピーしたり画像をドラッグしたりできます。Apple TV は読み取り専用です。

4. 画像を取り込む

写真、ファイル、ドラッグ＆ドロップ、画像リンクを利用できます。作品のウェブページは画像 URL ではありません。リンクの取り込みに失敗したら、ダウンロードが許可された画像ファイルを使ってください。ポスターと人物画像は 2:3、背景とエピソード画像は 16:9 です。

公開されていても自由に再利用できるとは限りません。利用規約と画像ライセンスを確認し、自作または使用許可のある素材を使ってください。

5. 変更を保存する

番組全体、現在のシーズン、エピソードを同じ画面で編集します。エピソードはタイトル、あらすじ、画像のみです。変更の保存で編集中の変更済み項目をすべて保存します。アプリ終了後は未保存の画像を復元できません。

簡単なルール

  • 1つ使用 Title (Year) 1つのメインビデオで、映画ごとのフォルダ。
  • 使用する Show (Year)/Season 01/Show - S01E01 エピソード用に。
  • NFO ファイルはオプションです。これがない場合、Vanto はフォルダー名とファイル名からメディア構造を構築します。
  • フォルダとファイル名はメディアIDを確立します。NFO、アートワーク、字幕はプレゼンテーションの詳細を追加します。
  • Vanto の外でファイルを変更した場合はソースを更新してください。Vanto 内で保存した編集は現在のライブラリに自動反映されます。
最も信頼性の高いアプローチ

名前はシンプルにし、年を含めてください。 シーズン、エピソード、またはフォルダーの関係を書き換えるためにNFOを使用しないでください。また、メディアのアイデンティティを表現するために複雑なリリース名に依存しないでください。

NFO、アートワーク、字幕はすべてオプションです。 ビデオのみをインデックス化することができます。これらのファイルが存在する場合、Vantoは明示的にバインドされたローカル情報を好みます。

映画

各ムービーフォルダにメインビデオを1つ保存します。 トレーラー、エキストラ、サンプル、インタビューを Trailers, Extras, Samples、または Interviews サブフォルダ。それらは別々のホームアイテムになることなく閲覧可能なままです。

Vantoは、ビデオと一致するベース名を持つNFOを好み、 movie.nfo 単一機能のフォルダに保存します。 Vantoは現在、1つのフォルダ内の複数のビデオをマルチバージョンアイテムにマージしていません。 複数のバージョンを保持している場合は、各バージョンに独自のムービーフォルダを指定します。

映画NFOの例を見る
<?xml version="1.0" encoding="UTF-8"?>
<movie>
  <title>Arrival</title>
  <originaltitle>Arrival</originaltitle>
  <year>2016</year>
  <plot>Movie summary</plot>
  <genre>Science Fiction</genre>
  <rating>7.9</rating>
  <uniqueid type="tmdb" default="true">329865</uniqueid>
</movie>

ショー、シーズン、エピソード

ショー名は、ショールート、シーズンフォルダのシーズン番号、ビデオファイル名のエピソード番号に由来します。 Season 00 そして S00E01 スペシャルのために。連続したエピソードにまたがるファイルは使用するかもしれません S01E01-E02別々のエピソードファイルは通常、より明確な進行状況とメタデータを提供します。

使用する tvshow.nfo ショーのために season.nfo 各シーズンフォルダ内にあり、各エピソードビデオに一致するNFOがあります。 NFO内のシーズンとエピソードの値は、スキャン中に見つかった階層に置き換わるものではありません。

番組、シーズン、エピソードのNFOの例を見る

番組: tvshow.nfo

<?xml version="1.0" encoding="UTF-8"?>
<tvshow>
  <title>Example Show</title>
  <originaltitle>Example Show</originaltitle>
  <year>2026</year>
  <plot>Show summary</plot>
  <genre>Drama</genre>
  <uniqueid type="tvdb" default="true">123456</uniqueid>
</tvshow>

シーズン：シーズン01/season.nfo

<?xml version="1.0" encoding="UTF-8"?>
<season>
  <title>Season One</title>
  <seasonnumber>1</seasonnumber>
  <plot>Season summary</plot>
</season>

エピソード: ビデオと一致する NFO

<?xml version="1.0" encoding="UTF-8"?>
<episodedetails>
  <title>Episode One</title>
  <showtitle>Example Show</showtitle>
  <season>1</season>
  <episode>1</episode>
  <aired>2026-01-01</aired>
  <plot>Episode summary</plot>
</episodedetails>

ビデオフレームのアートワーク

確認されたアートワークが存在しない場合、Vantoはビデオフレームをフォールバックとして使用することがあります。 SMBとWebDAVは表示されるアイテムに優先順位を付けるため、残りのアートワークは後で更新した後、または詳細ページを開いたときに表示される可能性があります。

外部字幕

Arrival (2016).mkv
Arrival (2016).en.srt
Arrival (2016).en.forced.ass
Arrival (2016).zh-Hant.vtt
  • 次のような言語タグを使用します。 zh-Hans, zh-Hant, en、または ja.
  • などの一般的な接尾辞 forced 保持される場合があります。プレーヤーでの字幕選択は依然として権威を持っています。
  • テキスト形式には、SRT、ASS、SSA、VTT、およびSMIが含まれます。 画像字幕には、PGS、SUP、および同名IDX +サブペアが含まれます。
  • NFO には外部字幕をリストしないでください。これらは、特定のビデオにバインドされた独立したファイルのままです。
  • 同じ言語の異なる字幕が複数ある場合は、 .2から始まる連番を追加します。例： Arrival (2016).en.2.srt。同一内容は重複して保存されません。

ソースと編集

書き込み可能な SMB または WebDAV に接続すれば、iPhone、iPad、Mac で NFO を無料編集。Apple TV は読み取り専用です。

映画とシリーズのタイトル、あらすじ、画像、キャストを編集できます。

同じページでシーズンとエピソードを切り替え。各話の編集はタイトル、あらすじ、カバーだけでシンプルに。

シーズンはタイトル、あらすじ、ポスター、背景を編集できます。各話はタイトル、あらすじ、16:9 カバーのみで、評価、放送日、キャストは編集しません。

ソーススキャンして読むVantoで返信する
Local動画、NFO、アートワーク、字幕提供されていません。ファイルシステムでこれらのファイルを管理します
SMB / WebDAV動画、NFO、アートワーク、字幕フォルダの権限が許可されている場合、iPhone、iPad、およびMacでサポートされています
Apple TVスキャンしたコンテンツの読み取りと表示読み取り専用

書き込み可能な SMB および WebDAV の詳細ページでは、iPhone、iPad、Mac から映画、番組、選択したシーズンまたはエピソードの NFO とアートワークを作成・更新できます。オンラインでダウンロードした字幕と読み込んだ字幕ファイルは、既定で動画と同じフォルダに保存されるため、同じ NAS ソースを使う他のデバイスでも更新後に利用できます。Vanto はデバイス側に二重のコピーを保持しません。NAS に書き込まれていないことが明確な場合に限り、このデバイスだけに保存できます。Apple TV は NAS に書き込まず、オンライン字幕をそのデバイスに保存します。

書き込みスコープ

この編集セッションで変更した下書きだけを保存し、未変更のシーズンやエピソードは書き換えません。NAS の対象フォルダで作成、置換、名前変更、削除が許可されていることを確認してください。

互換性と高度なルール

Jellyfin、Kodi、および別の認識された名前を表示
  • Kodiとの互換性のために、 season01-poster.jpg そして season01-fanart.jpg show rootにあります。 推奨されるVantoとJellyfinのレイアウトは poster.jpg そして fanart.jpg シーズンフォルダー内。
  • 次のようなKodiフィールド namedseason そして seasonplot にとどまる可能性があります tvshow.nfo、しかしVantoはシーズンタイトルとサマリーを season.nfo シーズンフォルダー内。
  • Vantoは次のことを認識しています 1x01、ローカライズされたシーズンフォルダ名、およびその他の一般的なパターン。 新しく整理されたメディアの場合は、このページのメインレイアウトを使用してください。
  • タイトルがあいまいな場合は、明示的に uniqueid ファイル名に埋め込まれたアプリ固有のIDに依存するのではなく、NFOに送信されます。

チェックとトラブルシューティング

  • UTF-8 XML と正しいルート要素を使用します。 movie, tvshow, season、または episodedetails.
  • 各 NFO は最大 2 MB です。 Vanto は最大 32 人のキャスト メンバーを読み取ります。
  • 不明な XML 要素は無視され、スキャンや再生はブロックされません。
  • 変更が表示されない場合は、ソースを更新する前に、名前、XML、大文字と小文字、アートワークの場所、書き込み権限を確認してください。
